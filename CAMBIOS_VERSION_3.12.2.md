# Cambios versión web 3.12.2

- Corrige fotografías de respaldo que no se visualizaban por permisos privados de Google Drive.
- Agrega visor autenticado mediante Apps Script; no requiere hacer pública la carpeta.
- Carga todas las miniaturas de la galería con sesión y permisos del usuario.
- Conserva múltiples fotografías por ruta y permite abrir cada una individualmente.
- Guarda el ID real de Drive junto con cada evidencia nueva.
- Mantiene compatibilidad con evidencias ya registradas mediante extracción del ID desde la URL.
