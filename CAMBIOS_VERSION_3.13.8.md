# Cambios versión web 3.13.9

- El Conductor puede cargar documentos propios por defecto.
- Los documentos quedan asociados a la cuenta conectada y a la ficha del Conductor cuando existe.
- Cada carga del Conductor queda como Pendiente de revisión.
- Todos los Administradores reciben una notificación única para revisar el documento.
- El Administrador puede bloquear o restaurar el acceso desde Usuarios → Permisos → Documentos → Crear.
- El bloqueo se aplica en el botón, formulario, carga a Drive y servidor, sin cerrar la sesión.
- Los cambios de acceso quedan registrados en Auditoría.
