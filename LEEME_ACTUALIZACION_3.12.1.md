# Actualización web 3.12.1

1. Reemplace los archivos web anteriores por los incluidos en este ZIP.
2. Reemplace el código de Google Apps Script por `Codigo_Completo.gs`, o actualice los archivos `.gs` modulares.
3. Ejecute una vez `actualizarSistema()` desde Apps Script y autorice los permisos.
4. Cree una nueva versión del despliegue web.
5. Abra la URL `/exec` y fuerce una recarga completa del navegador.

La carpeta de Drive configurada para fotografías debe permitir edición a la cuenta que ejecuta Apps Script.
