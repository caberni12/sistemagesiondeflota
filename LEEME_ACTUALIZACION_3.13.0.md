# Actualización a 3.13.1

1. Reemplace todos los archivos web.
2. Sustituya el contenido del proyecto de Google Apps Script por `Codigo_Completo.gs`.
3. Ejecute una vez `actualizarSistema()`.
4. Autorice los permisos solicitados.
5. Publique una nueva versión de la aplicación web.
6. Recargue con Ctrl + F5.

## Otorgar acceso a Conexiones en línea

1. Ingrese como Administrador.
2. Abra Usuarios.
3. Pulse el botón de permisos del usuario.
4. Seleccione Permisos personalizados.
5. En `Conexiones en línea · acceso delegado`, marque únicamente `Ver`.
6. Guarde.

El usuario verá el módulo automáticamente en su entorno. Solo un Administrador puede realizar esta acción.
