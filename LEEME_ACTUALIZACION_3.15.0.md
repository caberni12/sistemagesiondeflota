# Actualización web 3.15.0

1. Sustituya completamente los archivos web anteriores.
2. Reemplace el proyecto de Apps Script por el nuevo `Codigo_Completo.gs`.
3. Ejecute:

   `actualizarSistema();`

4. Publique una nueva versión del despliegue.
5. Utilice la dirección terminada en `/exec`.
6. Recargue la web con `Ctrl + F5`.

La limpieza de caché del navegador es importante porque `mapa.js`, `conexion.js` y `aplicacion.js` contienen el nuevo motor de rendimiento.
