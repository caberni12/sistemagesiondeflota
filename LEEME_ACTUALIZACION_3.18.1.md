# Actualización web 3.18.1

1. Reemplace completamente los archivos web por los incluidos en esta carpeta.
2. Sustituya todo el contenido de Apps Script por `Codigo_Completo.gs`.
3. Ejecute `actualizarSistema();` desde el editor de Apps Script.
4. Autorice los permisos solicitados para hojas, activadores y Google Drive.
5. Publique una nueva versión del despliegue.
6. Utilice la URL que termina en `/exec`.
7. Recargue la web con `Ctrl + F5`.

## Primera revisión

1. Inicie sesión como Administrador.
2. Abra **Oficina Virtual**.
3. Pulse **Revisar ahora**.
4. Active **Modo automático** desde el menú de usuario si desea reparaciones técnicas seguras.
5. Compruebe que la alerta técnica del activador desaparezca después de la verificación.
6. Compruebe el centro de notificaciones y el módulo Alertas.

El modo automático no elimina registros ni cambia datos operacionales. Las alertas operacionales solo pueden cerrarse con una cuenta Administrador después de validar la situación. Un Conductor únicamente puede informar una falla; Oficina Virtual la entrega a los Administradores sin ejecutar cambios.
