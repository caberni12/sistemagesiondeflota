# Mejoras versión 2.8.2

## Check-in vehicular visible

- Los 16 controles preoperacionales aparecen directamente dentro del módulo Check-in vehicular.
- Ya no es necesario abrir una ventana para descubrir la lista de chequeo.
- Contador y barra de avance de controles revisados.
- Botón para marcar todos los controles como conformes y botón para limpiar respuestas.
- Estados visuales: Sin revisar, Conforme, Con falla y No aplica.
- Toda falla exige una observación antes de guardar.
- Los controles críticos continúan bloqueando la operación.
- Se conserva aprobación del supervisor para observaciones leves.
- En usuarios sin permiso CHECKIN:CREAR se muestra la lista y una advertencia clara de permisos.
- Diseño adaptable para teléfonos, tabletas y escritorio.
