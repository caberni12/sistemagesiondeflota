# Mejoras versión 2.9.0 — Personalización visual

- Nuevo editor de colores dentro del módulo Configuración.
- Paleta global guardada en la base central y compatible con almacenamiento local.
- Colores configurables: principal, secundario, acento, fondo, superficie, texto, texto secundario, borde, menú, éxito, advertencia y peligro.
- Colores independientes para fondos, superficies, textos y bordes del modo oscuro.
- Cinco paletas predefinidas: verde profesional, azul corporativo, naranja operativo, morado ejecutivo y gris neutro.
- Vista previa inmediata y comprobación de contraste.
- Restauración de colores originales y descarte de cambios no guardados.
- Aplicación automática al acceso, main.html y todos los módulos dentro del iframe.
- El tema se conserva en dispositivos nuevos mediante la configuración central.
- Mantiene la estructura de carpeta única para GitHub.
