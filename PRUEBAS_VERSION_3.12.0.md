# Pruebas recomendadas — versión 3.12.0

## Evidencia de ruta

1. Inicie sesión como Conductor con una ruta asignada.
2. Abra Rutas y pulse `📷 Cargar respaldo`.
3. Tome dos fotografías y confirme que la carga comienza inmediatamente.
4. Agregue una observación y guarde.
5. Compruebe el enlace en la ruta y el archivo en Google Drive.
6. Verifique la notificación recibida por un Administrador o Supervisor.

## Alertas

1. Cree una mantención con fecha dentro de siete días.
2. Pulse `⚡ Revisar anomalías` o espere la ejecución programada.
3. Confirme que se crea una sola alerta y no se duplica al volver a revisar inmediatamente.
4. Repita con un documento vencido y un check-in crítico.
5. Compruebe que el mapa continúa respondiendo durante la revisión automática.

## Pantalla completa

1. Abra Ubicación en tiempo real.
2. Pulse `⛶ Pantalla completa`.
3. Verifique que el mapa ocupa toda la pantalla y conserva controles y marcadores.
4. Pulse `↙ Volver al tamaño normal`.
5. Confirme que el mapa se redibuja correctamente.
